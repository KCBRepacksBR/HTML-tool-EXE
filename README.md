# App Weaver

Crie um aplicativos capaz de criar aplicativo para Windows 11 e 10 usando arquivo html,
adicione a esse aplicativos opção como: Nome do Aplicativo, Versão, Ícone, Escolher arquivo HTML, Link do arquivo de Versão do GitHub e Link fixo do arquivo de download do GitHub.

E o aplicativo a ser criado usando esse app deve ter um servidor local e Butão direito do Mouse com Opção: Copiar, Colar e Recortar e sistema de atualização via GitHub usando  link do arquivo de versão e Link fixo do GitHub para baixar os arquivos e atualizar.

This project was built with [Lovable](https://lovable.dev).
